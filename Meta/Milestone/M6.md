## Test Plan

### E2E 测试场景

1. **完整 Capture 流程**
   - 按快捷键 → 输入 → 保存 → 查看标签和摘要

2. **搜索和浏览流程**
   - 打开 Library → 搜索 → 筛选 → 查看详情

3. **演化追踪流程**
   - 保存相似内容 → 看到提示 → 查看 Trace

4. **Habits 流程**
   - 创建 Habit → 保存匹配内容 → 执行 Habit

5. **Message Refinement 流程**
   - 截屏 → 输入内容 → 选择风格 → 复制结果
