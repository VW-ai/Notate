# Milestone 1: Core Infrastructure & Quick Capture

- **Status**: Draft
- **Target Date**: TBD
- **Owner**: TBD

## Goal

Build the foundational infrastructure and implement the core Quick Capture functionality that allows users to capture thoughts via a global hotkey overlay.

## Scope

### In Scope
- Tauri 2.0 project setup with React frontend and Rust backend
- SQLite database schema and basic CRUD operations
- Global hotkey system for overlay activation
- Quick Capture overlay UI (basic input)
- Basic capture types: Thought, Link
- Local file storage structure

### Out of Scope
- AI features (tagging, summarization, evolution detection)
- Library views (Timeline, Canvas, Traces, Types)
- Habits system
- Message Refinement
- Vector storage (LanceDB)
- File/Image capture types

## Deliverables

| Deliverable | Description | Acceptance Criteria |
|-------------|-------------|---------------------|
| Project Setup | Tauri + React + Rust scaffolding | `npm run tauri dev` launches app |
| Database | SQLite with core schema | Captures can be created/read/updated/deleted |
| Hotkey System | Global hotkey registration | `Cmd+Shift+Space` opens overlay from any app |
| Overlay UI | Basic Quick Capture interface | User can input text and save |
| Capture Storage | Save captures to database | Captures persist across app restarts |

## Test Plan

1. **Hotkey Test**: Press `Cmd+Shift+Space` from any application, overlay should appear
2. **Capture Test**: Type text, press Enter, capture should be saved
3. **Persistence Test**: Restart app, previous captures should still exist
4. **Close Test**: Press ESC or click outside, overlay should close

## Risks

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Tauri global hotkey issues on macOS | Medium | High | Test early, have fallback keybind |
| SQLite performance with many captures | Low | Medium | Add indexes, test with large datasets |
| Overlay window focus issues | Medium | Medium | Research Tauri window management APIs |

## Notes

This milestone establishes the core user experience loop:
1. User presses hotkey anywhere
2. Overlay appears instantly
3. User types thought
4. User presses Enter
5. Thought is saved, overlay closes

Speed is critical - the entire flow should feel instant (< 500ms response time).
