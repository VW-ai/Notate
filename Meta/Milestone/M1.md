# Milestone 1: Core Infrastructure & Quick Capture

- **Status**: Draft
- **Target Date**: TBD
- **Owner**: TBD

## Goal

搭建项目基础设施，实现全局快捷键唤起 Overlay 并保存 Capture 的核心流程。

## Scope

### In Scope
- Tauri 2.0 项目搭建（React 前端 + Rust 后端）
- SQLite 数据库 Schema 和基础 CRUD
- 全局快捷键系统
- Quick Capture Overlay UI（基础输入）
- 基础 Capture 类型：Thought、Link
- 本地文件存储结构
- Data Driven 配置系统（YAML）

### Out of Scope
- AI 功能（打标签、摘要、演化检测）
- Library 视图
- Habits 系统
- Message Refinement
- LanceDB 向量存储
- File/Image Capture 类型

## Deliverables

| Deliverable | Description | Acceptance Criteria |
|-------------|-------------|---------------------|
| Project Setup | Tauri + React + Rust 项目结构 | `npm run tauri dev` 启动应用 |
| Database | SQLite 核心表结构 | Capture 可以增删改查 |
| Config System | YAML 配置加载 | 配置从 defaults.yaml 正确加载 |
| Hotkey System | 全局快捷键注册 | `⌘+Shift+Space` 从任何应用唤起 Overlay |
| Overlay UI | Quick Capture 界面 | 用户可以输入文本并保存 |
| Capture Storage | Capture 存储到数据库 | 重启应用后数据持久化 |

## Dependencies

- Tauri 2.0 stable
- Node.js 20+
- Rust toolchain

## Test Plan

1. **快捷键测试**：从任何应用按 `⌘+Shift+Space`，Overlay 应该出现
2. **保存测试**：输入文本，按 Enter，Capture 应该保存
3. **持久化测试**：重启应用，之前的 Captures 应该还在
4. **关闭测试**：按 ESC 或点击外部，Overlay 应该关闭
5. **配置测试**：修改 config.yaml，重启后配置生效

## Risks

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Tauri 全局快捷键在 macOS 的兼容性 | Medium | High | 早期测试，准备备选方案 |
| SQLite 大数据量性能 | Low | Medium | 添加索引，大数据集测试 |
| Overlay 窗口焦点问题 | Medium | Medium | 研究 Tauri 窗口管理 API |

## Success Metrics

- Overlay 唤起延迟 < 200ms
- 保存响应 < 200ms
- 从想法到保存完成 < 3 秒

## Notes

这个 Milestone 建立核心用户体验循环：
1. 用户在任何地方按快捷键
2. Overlay 立即出现
3. 用户输入想法
4. 用户按 Enter
5. 想法保存，Overlay 关闭

**速度是关键** —— 整个流程必须感觉即时。
