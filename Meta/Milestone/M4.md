# Milestone 4: Evolution Tracking

- **Status**: Draft
- **Target Date**: TBD
- **Owner**: TBD

## Goal

实现演化追踪核心功能：保存时检测相似内容并提示用户，自动生成 Trace，在详情 Panel 展示相关内容和轨迹。

## Scope

### In Scope
- 演化检测（保存时提示）
- Trace 自动生成
- Trace 标题 AI 生成
- Trace 标题编辑
- 详情 Panel - Related 模块
- 详情 Panel - Trace 模块
- Traces 视图完善
- trace_created / trace_updated 事件

### Out of Scope
- Trace 手动合并/拆分（MVP 后）
- 周报功能（MVP 后）

## Deliverables

| Deliverable | Description | Acceptance Criteria |
|-------------|-------------|---------------------|
| Evolution Detection | 演化检测 | 保存相似内容时显示提示 |
| Trace Generation | Trace 自动生成 | ≥3 条相似内容自动形成 Trace |
| Trace Title | 标题生成和编辑 | AI 生成标题，可 inline 编辑 |
| Related Module | 详情 Related | 显示语义相关的其他 Captures |
| Trace Module | 详情 Trace | 显示所属 Trace 和位置 |
| Traces View | 完整轨迹视图 | Trace 卡片可展开收起 |

## Test Plan

1. **检测测试**：保存与历史相似的内容，应显示"你 X 天前也记过类似的"
2. **Trace 测试**：同话题保存 3 条后，应自动生成 Trace
3. **Related 测试**：打开详情 Panel，应显示相关 Captures
4. **Trace 模块测试**：有 Trace 时显示位置和时间线
5. **编辑测试**：可以 inline 编辑 Trace 标题

## Notes

演化追踪是 Notate 的核心差异化功能。

> "人对自己观点变化的感知出奇地差。改变了想法，但不知道自己改变了。"

这个功能帮助用户发现自己的想法如何随时间演变。

设计原则：
- 提示轻量，不打扰
- 默认先存后提示
- 自动形成 Trace，用户无需手动整理
