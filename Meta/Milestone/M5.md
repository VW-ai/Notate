# Milestone 5: Habits System

- **Status**: Draft
- **Target Date**: TBD
- **Owner**: TBD

## Goal

实现 Habits 系统，包括系统默认 Habits 和用户自定义 Habits，让用户可以用自然语言定义内容整理规则。

## Scope

### In Scope
- 系统默认 Habits（链接提取、图片 OCR、PDF 索引）
- Habits 页面（列表、创建、编辑）
- 自然语言规则解析（Habit Executor Agent）
- 保存时 Habit 匹配和推荐
- Habit 执行
- Overlay `/habit` 命令
- Habit 开关控制

### Out of Scope
- 复杂的多步骤自动化
- 第三方服务集成

## Deliverables

| Deliverable | Description | Acceptance Criteria |
|-------------|-------------|---------------------|
| Default Habits | 系统默认 Habits | 链接、图片、PDF 自动处理 |
| Habits Page | Habits 管理页面 | 可查看、创建、编辑、开关 |
| Habit Creation | 自然语言创建 | 输入描述，AI 解析为规则 |
| Habit Matching | Habit 匹配 | 保存时推荐匹配的 Habits |
| Habit Execution | Habit 执行 | 选择 Habit 后执行规则 |
| Overlay Command | /habit 命令 | Overlay 中可查看/创建 Habit |

## Dependencies

- M2 完成（需要 AI 能力）
- M1 完成（需要基础设施）

## Test Plan

1. **默认 Habit 测试**：保存链接，自动提取标题和摘要
2. **创建测试**：用自然语言创建 Habit，AI 正确解析
3. **匹配测试**：保存 YouTube 链接，推荐相关 Habits
4. **执行测试**：选择 Habit，执行后 Capture 更新
5. **开关测试**：关闭 Habit 后不再触发

## Risks

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| 自然语言解析不准确 | Medium | Medium | 显示解析结果让用户确认 |
| Habit 执行失败 | Medium | Low | 不阻塞保存，显示失败提示 |
| 规则冲突 | Low | Low | 用户选择优先执行哪个 |

## Success Metrics

- 规则解析 < 3s
- Habit 匹配 < 200ms
- Habit 执行 < 5s

## Notes

Habits 是**整理规则**，不是**任务执行**。

设计原则：
- 用户用自然语言描述规则
- AI 理解并转化为可执行流程
- 保存时推荐，用户有控制感
- 不主动执行复杂操作
