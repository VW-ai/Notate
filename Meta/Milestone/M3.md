# Milestone 3: Library Views

- **Status**: Draft
- **Target Date**: TBD
- **Owner**: TBD

## Goal

实现 Library 的四个视图（Timeline、Canvas、Traces、Types），让用户可以浏览和组织自己的知识库。

## Scope

### In Scope
- App 主界面框架
- 侧边栏导航
- Timeline 视图（时间线）
- Canvas 视图（知识地图）
- Traces 视图（演化轨迹）- 占位
- Types 视图（类型统计）
- 语义搜索
- 标签筛选
- 无限滚动/虚拟列表

### Out of Scope
- 演化检测和 Trace 自动生成（M4）
- 详情 Panel 的 Related 和 Trace 模块（M4）
- Habits 页面（M5）
- Home 页面（M6）

## Deliverables

| Deliverable | Description | Acceptance Criteria |
|-------------|-------------|---------------------|
| App Shell | 主界面框架 | 侧边栏 + 主内容区布局 |
| Timeline | 时间线视图 | 按时间倒序显示 Captures |
| Canvas | 知识地图视图 | Tag 区块布局，可缩放平移 |
| Traces | 轨迹视图 | 显示 Trace 列表（占位） |
| Types | 类型统计视图 | 显示各类型数量统计 |
| Search | 语义搜索 | 输入查询，返回相关 Captures |
| Filter | 标签筛选 | 点击标签筛选内容 |

## Dependencies

- M2 完成（需要 Embedding 和标签）

## Test Plan

1. **Timeline 测试**：打开 Library，默认显示 Timeline，按时间排序
2. **Canvas 测试**：切换到 Canvas，Tag 区块按语义位置分布
3. **搜索测试**：输入查询，返回语义相关的 Captures
4. **筛选测试**：点击标签，只显示该标签的内容
5. **详情测试**：点击卡片，右侧显示详情 Panel

## Risks

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Canvas 性能问题 | Medium | High | 视口外不渲染，缓存布局 |
| 虚拟滚动复杂度 | Medium | Medium | 使用成熟的 react-window |
| UMAP 计算耗时 | Medium | Medium | 后台计算，缓存结果 |

## Success Metrics

- Timeline 加载 < 100ms
- Canvas 渲染 < 200ms（缓存命中）
- 搜索响应 < 500ms
- 滚动流畅 60fps

## Notes

这个 Milestone 建立用户浏览知识库的核心体验。

设计原则：
- 视图切换即时响应
- 大数据量下保持流畅
- Canvas 布局语义化，相关内容靠近
