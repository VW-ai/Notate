# Milestone 2: AI Integration

- **Status**: Draft
- **Target Date**: TBD
- **Owner**: TBD

## Goal

集成 Gemini AI，实现自动打标签、摘要生成和向量 Embedding，为后续的语义搜索和演化检测打下基础。

## Scope

### In Scope
- Gemini API 集成
- LanceDB 向量存储
- 自动打标签（Organizer Agent）
- 自动摘要生成
- Embedding 生成和存储
- Image/File Capture 类型
- 图片 OCR
- PDF 文本提取
- AI 异步处理队列

### Out of Scope
- 演化检测（M4）
- Habits 系统（M5）
- Message Refinement（M6）
- Library 视图（M3）

## Deliverables

| Deliverable | Description | Acceptance Criteria |
|-------------|-------------|---------------------|
| Gemini Integration | AI API 封装 | 能调用 Embedding、Tagging、Summary |
| Vector Storage | LanceDB 集成 | Embedding 可存储和查询 |
| Auto Tagging | 自动打标签 | Capture 保存后自动生成标签 |
| Auto Summary | 自动摘要 | 长内容自动生成摘要 |
| Image Support | 图片 Capture | 图片可上传、OCR、存储 |
| File Support | 文件 Capture | PDF 可上传、提取文本 |
| Async Queue | 异步处理队列 | AI 任务不阻塞主流程 |

## Dependencies

- M1 完成
- Gemini API Key
- LanceDB Rust 绑定

## Test Plan

1. **标签测试**：保存 Capture 后，几秒内应自动生成标签
2. **摘要测试**：长内容保存后，应自动生成摘要
3. **图片测试**：上传图片，OCR 应提取文字
4. **PDF 测试**：上传 PDF，应提取内容
5. **搜索测试**：保存后，应能通过语义搜索找到

## Risks

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Gemini API 限流 | Medium | High | 实现请求限流，缓存 |
| Embedding 质量 | Low | Medium | 测试多语言场景 |
| 异步处理复杂度 | Medium | Medium | 清晰的任务状态管理 |

## Success Metrics

- Embedding 生成 < 2s
- 标签生成 < 3s
- 摘要生成 < 3s
- 图片 OCR < 5s

## Notes

这个 Milestone 引入 AI 能力，是 Notate 智能化的基础。

关键设计原则：
- AI 处理异步执行，不阻塞用户操作
- 用户先看到 Capture 保存成功，AI 结果后续更新
- 失败不影响基本功能
