# Library 功能设计

**版本:** 1.0  

---

## 概述

Library 是浏览和组织知识库的主界面。

**四个视图**：

| 视图 | 回答问题 |
|------|----------|
| Timeline | 我最近记了什么 |
| Canvas | 我的知识分布在哪些领域 |
| Traces | 我的想法怎么变的 |
| Types | 我有哪些类型的内容 |

---

## 页面结构

```
┌─────────────────────────────────────────────────────┐
│  Library     [Timeline] [Canvas] [Traces] [Types]   │
├─────────────────────────────────────────────────────┤
│  🔍 搜索...                                ⌘ + F    │
│  Tags: [#tag1] [#tag2] [全部]                       │
├─────────────────────────────────────────────────────┤
│                                                     │
│                   视图内容区域                       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

---

## Timeline 视图

按时间倒序展示，按日期分组。

**卡片内容**：类型图标 + 内容预览(2行) + 标签 + 时间

**交互**：
- 点击卡片 → 详情 Panel
- 点击标签 → 筛选
- 滚动 → 无限加载

---

## Canvas 视图

Tag 区块布局，语义相近的 Tag 靠近。

```
┌───────────────┐  ┌───────────────┐
│   #Startup    │  │   #Research   │
│  ┌───┐ ┌───┐  │  │  ┌───┐ ┌───┐ │
│  │💭 │ │🔗 │  │  │  │📄 │ │💭 │ │
│  └───┘ └───┘  │  │  └───┘ └───┘ │
└───────────────┘  └───────────────┘
```

**交互**：
- 滚轮/双指 → 缩放
- 拖拽空白 → 平移
- 点击卡片 → 详情 Panel
- 点击 Tag 标题 → 筛选

**布局算法**：后端计算 Tag 的 2D 语义位置（降维）

---

## Traces 视图

每个 Trace 一行，横向时间线。

```
┌─────────────────────────────────────────────────────┐
│ B2C vs B2B 决策                              [编辑] │
│ ┌─────┐ → ┌─────┐ → ┌─────┐ → ┌─────┐            │
│ │1/15 │   │2/3  │   │2/20 │   │3/5  │            │
│ │B2C..│   │B2B..│   │niche│   │确定 │            │
│ └─────┘   └─────┘   └─────┘   └─────┘            │
└─────────────────────────────────────────────────────┘
```

**交互**：
- 点击紧凑卡片 → 展开
- 再点 → 收起
- "查看详情" → 详情 Panel
- 点击标题 → inline 编辑

---

## Types 视图

按类型分类统计。

**用户输入类型**：Thoughts / Links / Files

**AI 识别实体**：People / Companies / Projects

**交互**：点击类型 → 切换到 Timeline 并筛选

---

## 详情 Panel

右侧滑出面板，显示：
1. 完整内容 + 标签 + 时间
2. 所属 Trace（如有）+ 轨迹时间线
3. 相关内容列表

**无 Trace 时**：显示引导文案"当你有更多相关想法时，会自动形成轨迹"

---

## 前端要点

**状态管理**：
- currentView
- searchQuery, selectedTags
- 各视图数据（timelineCaptures, canvasLayout, traces）
- detailPanelOpen, selectedCaptureId

**性能优化**：
- Timeline 虚拟滚动（react-window）
- Canvas 视口外不渲染
- 搜索 debounce 300ms
