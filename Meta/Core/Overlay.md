# Overlay 功能设计

**版本:** 1.0  

---

## 概述

Overlay 是用户主要交互入口，通过全局快捷键唤起。

**核心指标**：
- 唤起延迟 < 200ms
- 保存响应 < 500ms
- 想到记录 < 3 秒

---

## 唤起与关闭

| 操作 | 方式 |
|------|------|
| 唤起 | `⌘ + Shift + Space`（可配置） |
| 关闭 | ESC / 点击外部 / 保存后自动 |

---

## 状态流转

```
空闲 → 输入 → 保存中 → 保存成功 → 演化提示（可选） → 关闭
```

## 消息优化模式

**流程**：截屏/粘贴上下文 → 输入想说的 → 选风格 → 生成 → 复制

**风格选项**：专业 / 礼貌 / 友好 / 简短 / 详细

---

## 快捷键

| 快捷键 | 作用 |
|--------|------|
| Enter | 保存 / 执行选中 Habit |
| ⌘ + Enter | 强制保存（跳过 Habit） |
| ESC | 关闭 |
| ↑ / ↓ | 切换 Habit |
| Tab | 切换类型 |

---

## 前端要点

**状态管理**：
- isOpen, mode (capture/refine)
- inputValue, captureType
- matchingHabits, selectedHabitIndex
- evolutionHint, hintExpanded

**性能优化**：
- 窗口预创建，隐藏/显示切换
- Habit 匹配 debounce 300ms
- 保存后立即显示成功，AI 异步
