### 1.4 Message Refinement 流程

```
┌───────────────────────────────────────┐

│  ✓ Content pasted                     │
```

**Canvas 卡片样式（紧凑）**：

```
┌─────────────┐
│ 📝 1/15     │
│ 应该做B2C   │
│ 因为...     │
└─────────────┘
```

显示：类型 icon + 日期 + 内容前2行
不显示：Tag（已通过空间位置表达）

**交互**：
- 滚轮/双指：缩放
- 拖拽空白：平移
- 点击卡片：打开详情 Panel
- 点击 Tag 标题：筛选只看该 Tag

## 六、交互规范汇总

### 6.1 点击行为

| 位置 | 点击对象 | 行为 |
|------|----------|------|
| Canvas | 卡片 | 打开详情 Panel |
| Canvas | Tag 标题 | 筛选只看该 Tag |
| Traces | 紧凑卡片 | 展开 |
| Traces | 展开的卡片 | 收起 |
| Traces | 展开卡片的"查看详情" | 打开详情 Panel |
| Traces | Trace 标题 | Inline 编辑 |
| 详情 Panel | "查看完整轨迹" | 跳转 Traces 视图并定位 |
| Overlay | 演化提示 | 展开旧 capture 摘要 |

### 6.2 配置选项

| 功能 | 默认 | 可配置为 |
|------|------|----------|
| 捕捉时演化检测提示 | 先存后提示 | 静默标记 |

### 6.3 Trace 生成规则

- 条件：同话题 + 至少 3 条 capture
- 标题：AI 自动生成
- 编辑：用户可 inline 编辑标题
- 合并/拆分：MVP 不支持
